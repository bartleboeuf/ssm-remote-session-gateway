About SSM Remote Session Gateway

SSM Remote Session Gateway

Version Loading...

Cross-platform application to manage EC2 instances and establish secure connections via AWS Systems Manager (SSM).

Key Features
SSH Secure shell access via SSM port forwarding.
RDP Remote desktop for Windows instances.
Custom Forwarding Forward any port through SSM tunnels.
Secure No open SSH ports, uses AWS IAM & SSM.
Management View and filter EC2 instances efficiently.
Configurable Customizable port ranges & folder preferences.
About

SSM Remote Session Gateway is a cross-platform web application that simplifies managing EC2 instances and establishing secure connections through AWS Systems Manager Session Manager. This project is maintained and continuously improved based on real-world usage and feedback.

Maintainer: Bart LEBOEUF
Contributions, feedback, and improvement ideas are always welcome!
